## 阅读说明 Reading guide

- 分级条件中用“／”或“/”分隔的三个数值，依次对应 **铜 / Bronze → 银 / Silver → 金 / Gold**。门槛均包含等于值。 / Three values separated by slashes correspond to **bronze → silver → gold**. All thresholds are inclusive.
- 单次成就只有一次解锁，使用石质徽章。 / One-time achievements unlock once and use stone badges.
- Token 单位：**1M = 1,000,000（100 万）；1B = 1,000,000,000（10 亿）；1T = 1,000,000,000,000（1 万亿）**。 / Token units: **M = million, B = billion, T = trillion**.
- Harness 指使用模型的工具或客户端，按程序识别的来源类型统计。 / A harness is the tool or client used to access a model, counted by the source type recognized by the app.
- “条件”是解锁要求；“解说”是成就附带的趣味文案。中英文解说保留各自的本地化版本。 / The condition states the unlock requirement; flavor text is the accompanying playful copy. Each language retains its own localized wording.

### 满贯与故事全收集 Collection dependencies

三个满贯分别检查全部 27 项分级成就；已获更高等级也满足较低等级。单次成就不参与铜银金满贯。

Each Slam checks all 27 tiered achievements. A higher earned tier also satisfies lower tiers. One-time achievements do not contribute to bronze, silver or gold Slams.
