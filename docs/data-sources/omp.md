# Oh My Pi 数据源

简体中文 · [English](omp.en.md)

来源管理可扫描 `~/.omp/agent`。也可以选择 OMP home、agent 目录、`sessions`、`archive/sessions` 或单个项目目录。只选活动目录或单个项目时，另外的目录需要单独导入。使用自定义会话路径时，在「添加其他位置」选择包含会话文件的目录。

`CODEX_USAGE_OMP_HOMES` 可追加已确认的目录，路径分隔符沿用[数据来源](../10-data-sources.md#扫描与导入)中的约定。`CODEX_USAGE_OMP=0` 关闭自动发现，手动导入仍可用。扫描候选也包括 OMP 的 agent、会话目录环境变量及已存在的 profile 和 XDG 数据布局。

## 用量与费用

统计会话中已写入的模型回复和独立计量记录，包括子代理、advisor、标题和压缩等辅助调用。活动与归档的主会话及子会话按同一口径计入。

- 输入包含缓存读写和服务端编排输入。缓存命中是输入的子集。
- 输出已经包含推理。编排输出缺少推理细分时，推理量显示为未知。
- 优先使用有效的来源总量。组成字段完整时可求和，缺失明细显示为未知。

Waifu 根据记录中的模型、可识别的逐调用档位及现有价目估算 API 费用。Oh My Pi 用量计入普通日期范围，Codex 额度窗口只统计符合资格的 Codex 用量。

## 同步与历史

fork、撤销改写和归档复制有足够的调用身份时只计一次。来源文件消失或会话删除旧内容后，已经确认的消费继续保留。随后从原会话确认同一调用的计量修正时，更新对应事实。备份及冷历史继续使用[现有历史流程](../history-retention.md)。

支持带稳定 entry ID 的 v2/v3 会话。v1 日志需要上游提供稳定身份。缺少可靠响应标识的重挂载可能无法去重，来源从未写入的用量也无法恢复。解析时会短暂在内存中读取日志行，只保留用量和归属所需的字段。损坏的归档和无法确认身份的记录可在来源详情诊断。
