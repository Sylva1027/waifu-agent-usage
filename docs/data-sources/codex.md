# Codex 数据源

简体中文 · [English](codex.en.md)

来源管理中选择 Codex home，默认 `~/.codex`，也扫描本机 JetBrains 集成目录。可用 `CODEX_USAGE_HOMES` 追加目录。共同导入操作见[数据来源](../10-data-sources.md)。

## 日志与用量

读取 `sessions/`、`archived_sessions/` 下的 `.jsonl` 和 `.jsonl.zst`。同名两种格式并存时优先 `.jsonl`，压缩日志流式读取。

会话头提供 ID、工作目录和客户端来源，模型来自请求上下文。Token 记录提供累计或最近请求用量；同一会话跨文件续写时先换算增量，不逐行相加累计值。缓存命中属于输入，推理属于输出。

可信的最近请求输入用于上下文判断；累计输入不能代替单次请求上下文。缺失缓存写入或服务档位时保留未知，不补成零值或确定档位。

## 额度窗口

本机额度记录提供五小时／每周窗口及重置边界。只有符合条件的原生 Codex 用量进入额度窗口，其他工具使用同名模型仍不参与。认证、路由筛选及可选账户边界补齐见[看板说明](../12-dashboard.md#时间范围与额度)。

普通日期范围保留全部选中 Codex 用量。费用与额度百分比使用各自口径，不把 Token 筛选结果改写成账户百分比。

## 索引与更新

首次导入建立索引，后续在验证来源连续性后从检查点读取追加内容；截断、改写或格式切换重新校验。日常筛选查询已提交索引，后台同步时不展示半成品。

读取器升级可能补扫旧日志，已有历史和原始文件继续保留。无需手动删除索引，备份方法见[历史保留](../history-retention.md)。
