# 计价与自动更新

费用功能适用于 **Waifu**。按模型 API 单价估算用量对应的费用，可用 USD 或 CNY 查看。费用详情提供价格来源、服务档位和估算原因。

## 查看与修改

打开计价窗口，选择厂商，再选择模型。列表包含本机全历史使用过的模型，缺价模型也有编辑入口；搜索支持厂商中文名、英文名与模型名。

厂商内模型按发布日期倒序排列，未知日期放在末尾。新使用模型会显示未读状态，打开相应厂商窗口后确认已显示条目。

修改价格或汇率后点击“保存”生效，“取消”放弃草稿。“恢复自动汇率”也需保存才解除手动覆盖。后台更新不会覆盖尚未保存的编辑；并发保存冲突时保留草稿。

## 费用口径

费用是 API 等价估算，不是订阅扣费或服务商账单。总输入按普通输入、缓存读取和缓存写入拆分计价；推理已包含在总输出，不重复收费。

已知模型使用有效价目，按可用证据选择短／长上下文及 Standard／Fast 档位。明细缺失或冲突、上下文未知等情况会在详情中说明。未知付费模型使用适用币种的最低费率场景估算；无法可靠计价的部分保留为缺价。

普通历史费用随当前有效价目重算，不修改原始 Token。暂停刷新后的快照及历史导入实例使用固定价目，详见[历史导入](history-retention.md#完整包导出与导入)。

## 模型解析与免费规则

模型展示使用规范身份，去掉路由前缀并合并已知别名；原始日志和索引仍保留原名。价格依次按精确键、明确别名、未收录的 `-free` 后缀及带边界的最长已知前缀匹配。未知 Claude 版本保留缺价，不借用其他 Claude 版本价格。

- `codex-auto-review` 和 `hy4free` 使用专门的零费用规则，同名手动费率不会覆盖它们。
- `codex-auto-review` 的实际 Token、会话和额度窗口用量仍计入统计，真实额度百分比保持原值。对应政策见 [Codex 套餐说明](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)。
- 未收录的 `-free` 模型按零费率推算；同名明确价目优先。OpenCode 日志里的 `cost: 0` 不作为免费依据。

模型改名、路由归并和免费规则共用[价格模型映射](../public/pricing-models.js)。文档不另列整张单价表，具体费率以应用中的有效目录为准。

## 自动更新

服务启动后检查价格是否到期，此后约每小时检查一次；成功更新间隔至少 24 小时，失败后至少冷却 1 小时。也可在计价窗口立即更新。价格与汇率独立更新，一侧失败不会清除另一侧的有效值。

自动来源包括：

- Models.dev：可匹配的第一方模型目录。
- LiteLLM：OpenAI 价格备用来源。
- OpenRouter：精确匹配模型的参考价，补充已有官方适配之外的条目。
- StepFun、MiMo、Kimi、GLM：对应官方页面的人民币价格。
- Frankfurter：USD/CNY 显示汇率。

新使用的模型先匹配本地目录存档，必要时下载公开目录；只将实际用到且能可靠匹配的条目加入有效价目。来源缺字段或规则无法表达时保留已有有效值，并在模型详情中显示来源和继承情况。

联网仅获取公开价格与汇率，不发送本机模型名、用量、路径或正文。断网继续使用已有缓存或内置价格。OpenRouter 参考价的提供商口径见其 [FAQ](https://openrouter.ai/docs/faq)。

## 本地配置与兼容

有效价格优先级为：内置值 → 自动来源／缓存 → 手动字段覆盖；专门的免费规则优先于同名费率。

- `~/.codex-usage/pricing.json`：手动模型价格和汇率覆盖。
- `~/.codex-usage/pricing-auto.json`：自动价目与刷新状态。
- `~/.codex-usage/pricing-sources.sqlite`：公开目录存档，不是用量数据库。

旧全量配置与字段覆盖格式继续兼容。更新价目不需要清空用量索引。Lite 不计算费用，保留已有价格文件供切回 Waifu 使用。
